# Totally Radimals '98 — Promo Tape

An 81-second animated promo built entirely in JavaScript (canvas + Web Audio), starring the
Radimals from the Radimals Binder.

- `index.html` — open it in a browser and hit **PRESS START**. The chiptune soundtrack and all
  sound effects (dial-up screech, battle blips, evolution fanfare) are synthesized live.
  **SAVE VIDEO** records the promo in real time and downloads a `.webm`.
- `radimals-data.js` — sprites, habitat scenes, catchphrases and the RadPix font, extracted from the binder.
- `totally-radimals-98-promo.mp4` — a pre-rendered copy of the promo, ready to share.

Add `?t=SECONDS` to the URL to jump to a frame (e.g. `index.html?t=38.6`).
