# Totally Radimals '98

A complete handheld-style creature-collecting RPG with a sarcastic late-90s theme: 151 original
Radimals, four Hangout leaders, a frosted-tipped rival, Y2K Tower, and a legendary hiding on
The Internet.

- **Play:** open `www/index.html` in any browser (single self-contained file, works offline).
- **Project brief / design decisions:** `CLAUDE.md`
- **Ship to iOS:** `README-SHIP.md` (Capacitor → Xcode), plus `PRIVACY-POLICY.md`,
  `APP-STORE-LISTING.md`, `LEGAL-REVIEW.md`
- **Tests:** `tools/` (Playwright: audit, scripted playthrough, fuzz, sprite sheet)
- **Art:** all 151 Radimals hand-drawn — sprite source in `tools/sprites/`, roster sheet in `art/all-151-radimals.png`
- **Promo video:** `promo/`
